# Left Half Pyramid

**Difficulty:** `Easy`

## Problem

Given a non-negative integer n, print a left half pyramid of stars: n rows, where row i (1-indexed) contains exactly i stars, right aligned so every row is n characters wide, padded with leading spaces.

Read n from standard input. Print n lines. If n is 0, print nothing.

## Examples

### Example 1

**Input**
```
n = 4
```
**Output**
```
   *
  **
 ***
****
```

**Explanation:** Row 1 has 3 leading spaces then 1 star; row 4 has no leading spaces and 4 stars.

### Example 2

**Input**
```
n = 1
```
**Output**
```
*
```

**Explanation:** A single row with a single star and no leading spaces.

### Example 3

**Input**
```
n = 2
```
**Output**
```
 *
**
```

**Explanation:** Row 1 has 1 leading space then 1 star; row 2 has 2 stars.
