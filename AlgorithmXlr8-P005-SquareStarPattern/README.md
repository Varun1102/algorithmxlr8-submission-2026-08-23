# Square Star Pattern

**Difficulty:** `Easy`

## Problem

Given a non-negative integer n, print an n x n square made entirely of stars.

Read n from standard input. Print n lines, each containing exactly n star characters. If n is 0, print nothing.

## Examples

### Example 1

**Input**
```
n = 4
```
**Output**
```
****
****
****
****
```

**Explanation:** 4 rows, each with 4 stars.

### Example 2

**Input**
```
n = 1
```
**Output**
```
*
```

**Explanation:** A single row with a single star.

### Example 3

**Input**
```
n = 2
```
**Output**
```
**
**
```

**Explanation:** 2 rows, each with 2 stars.
